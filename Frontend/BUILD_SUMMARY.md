## 🚀 How to Use

### Run the App
```bash
cd auth
npm start
# Press i for iOS or a for Android
```

### Access Fashion App
1. From home screen, tap "Fashion Store" banner
2. Or navigate to `/fashionStore`

### Browse Products
1. View products on Home/Shopping tabs
2. Tap category to filter
3. Tap product to see details

### Add to Cart
1. Go to product details
2. Select size, color, quantity
3. Tap "Buy Now" or "Add To Cart"

### Save to Wishlist
1. Tap heart icon on any product
2. Heart fills with orange color
3. View in Wishlist tab
